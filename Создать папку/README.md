# TechPoint — интернет-магазин электроники

## Контрольная работа №1
**Тема:** «HTML и CSS: разработка многостраничного сайта».

TechPoint — учебный многостраничный сайт-каталог электроники. Проект демонстрирует семантическую HTML-разметку, единое меню, карточки товаров, таблицу характеристик, формы, CSS-переменные, Flexbox, Grid и базовое БЭМ-именование.

## Страницы
- `index.html` — главная, преимущества и популярные товары.
- `catalog.html` — каталог по категориям и сравнительная таблица.
- `product.html` — страница смартфона Nova X с характеристиками.
- `order.html` — форма оформления заявки.
- `contacts.html` — контактная информация, обратная связь и FAQ.

## Технологии
- HTML5: `header`, `nav`, `main`, `section`, `article`, `aside`, `footer`, формы и таблицы.
- CSS3: переменные в `:root`, псевдоклассы `:hover` и `:focus-visible`, Flexbox, Grid, позиционирование и адаптация под узкие экраны.
- БЭМ-подобное именование: `product-card__title`, `site-header__inner`, `order-form__field`.

## Как открыть проект
Открой `index.html` в браузере. Для публикации загрузи все файлы в GitHub-репозиторий и включи **Settings → Pages → Deploy from a branch → main → /(root)**.
