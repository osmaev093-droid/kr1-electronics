# Сайт ООО «РАЯНА»

Готовый статический сайт на HTML, CSS и JavaScript. Подходит для бесплатного размещения на GitHub Pages.

## Файлы
- `index.html` — содержание сайта
- `styles.css` — оформление и адаптация под телефон
- `script.js` — мобильное меню и год в подвале
- `assets/` — фотография руководителя и все изображения архитектуры (хранятся локально)

## Как опубликовать через GitHub Pages
1. Создайте новый публичный репозиторий на GitHub, например `rayana-site`.
2. Загрузите в репозиторий все файлы и папку `assets` из этого архива. Важно: `index.html` должен лежать в корне репозитория.
3. Откройте **Settings → Pages**.
4. В разделе **Build and deployment** выберите **Deploy from a branch**.
5. Выберите ветку **main** и папку **/(root)**, затем нажмите **Save**.
6. Через некоторое время GitHub покажет адрес опубликованного сайта в разделе Pages.

## Что желательно добавить перед публикацией
- Юридический адрес и ИНН/ОГРН, если хотите разместить реквизиты.
- Проверенные сведения о реализованных проектах и официальные фотографии объектов.

## Важно
Все изображения, включая фотографию руководителя и архитектурные фотографии, находятся внутри папки `assets` и не зависят от внешних фотохостингов. Для открытия сайта всё равно нужен интернет, но отдельные фотосервисы не требуются. Текст о компании составлен на основе сведений, предоставленных заказчиком. Перед публикацией проверьте точность должностей, званий и формулировок.
